# 20260519-FRONTEND — TRIBBO Redesign Status

## Contexte

Projet : SmartPronos → TRIBBO, application Angular de pronostics sportifs B2B (Coupe du Monde 2026).
Stack : Angular 21 (standalone, vite), Tailwind CSS v3 + PostCSS, SCSS (global only), TypeScript.

---

## 1. ÉTAT INITIAL (avant redesign)

### Architecture
- 10 composants/pages standalone : Landing, Login, Signup, MatchList, MatchCard, MatchStatusBadge, PredictionForm, PredictionFormPage, TopAppBar, BottomNav
- Routing : `/`→Landing, `/login`, `/signup`, `/home/match-list`, `/match/:id/prediction-form`, `/leaderboard`, `/company`, `/profile`
- Services : AuthService (Supabase), SupabaseService, MatchService, PredictionService
- Modèles : `MatchListItem`, `MatchTeam`, `MatchPredictionSummary`, `MatchStatus`, `PredictionFormValue`, `PredictionFormTeam`, `PredictionResponse`, `PredictionSubmissionError`

### Problèmes initiaux identifiés
1. **Thème dark** : thème sombre complet, pas de light mode
2. **SCSS monolithique** : 12 fichiers SCSS avec beaucoup de duplication
3. **Pas de Tailwind** : zéro Tailwind, tout en CSS personnalisé
4. **Marque SmartPronos** : pas de branding TRIBBO
5. **Layout mobile** : pas de bottom nav, apparence vieillotte
6. **Node.js** : WSL en v18, incompatible avec Angular CLI 21 (nécessite v20+)
7. **Assets** : logo-tribbo.png et logo-digitalizers.png placés dans `src/assets/` mais `angular.json` mal configuré — les assets étaient copiés à la racine du build, pas sous `/assets/`

---

## 2. ÉTAT ACTUEL (19 mai 2026)

### Stack & Config
- **Tailwind CSS v3.4.19** + PostCSS + autoprefixer + postcss-import
- `tailwind.config.js` : tokens TRIBBO complets (couleurs, fonts, border-radius, shadows)
- `postcss.config.js` : plugins Tailwind + autoprefixer
- `angular.json` : assets corrigé avec `"output": "assets"` pour `src/assets/`
- `styles.scss` : `@tailwind base/components/utilities` (plus de `@import` Sass deprecated)
- `index.html` : fonts Archivo Black / Inter / Space Mono, Material Symbols Outlined

### Design Tokens (tailwind.config.js)
```
tribbo-bg:      #F7F8FC
tribbo-surface: #FFFFFF
tribbo-primary: #1D4DFF
tribbo-text:    #1F2430
tribbo-success: #19C95B
tribbo-error:   #FF3B43
Fonts: Archivo Black (titres), Inter (corps), Space Mono (chiffres)
```

### Layout général (app.html)
- **Mobile** : TopAppBar + contenu scrollable + BottomNav fixée en bas (`fixed bottom-0`)
- **Desktop** : Top navbar horizontale (logo + nav : Accueil/Classement/Tribu/Profil + notifications) + contenu scrollable + footer Digitalizers fixe en bas
- **Auth screens** (landing/login/signup) : ni header ni nav, wrapper `max-w-lg` centré
- **Dashboard** (non-auth) : wrapper `max-w-7xl` centré, top nav full-width

### Pages

**Landing** (`/`)
- Logo `w-36 md:w-44`, titre "Tribbo\n2026" (6xl/8xl bleu), description, CTA "Commencer" avec ombre forte
- Lien "Déjà un compte ? Se connecter"

**Login** (`/login`)
- Logo + "Connexion" (3xl/4xl) + barre bleue
- Form `max-w-sm` centré : email + password + "Oublié ?"
- CTA "Se connecter" avec ombre
- Footer "Pas encore de compte ? S'inscrire"

**Signup** (`/signup`)
- Logo + "Créer un compte" (3xl/4xl) + barre bleue
- Form `max-w-sm` centré : prénom/nom (grid-2), email, password, confirm
- CTA "Créer mon compte"
- Footer "Déjà inscrit ? Se connecter"

**Dashboard (match-list)** (`/home/match-list`)
- Stats bar (card blanche) : points (3xl/4xl) + classement (2xl/3xl bleu)
- Filtres : Tous / Ouverts / Verrouillés / Terminés
- **Grille responsive** : `grid-cols-1 md:grid-cols-2 xl:grid-cols-3 gap-4 md:gap-6`
- Match cards dans la grille

**Match card**
- Card `rounded-xl p-5` avec `h-full flex flex-col`
- Flags text-4xl, VS Space Mono, nom équipes Archivo Black
- CTA bleu `bg-tribbo-primary` "Pronostiquer"

**Autres pages**
- PredictionFormPage, LeaderboardPage, CompanyPage, ProfilePage (placeholders simples)

### Composants partagés
- **BottomNav** : `h-16 w-full` fixée en bas mobile, 4 items avec Material Symbols
- **TopAppBar** : `h-14 w-full` avec logo w-9 + icône notifications
- **Desktop nav** : inline dans app.html, avec `(click)` handlers pour navigation forcée

### Auth bypass
- Login et signup redirigent directement vers `/home/match-list` sans appeler Supabase
- `withRouterConfig({ onSameUrlNavigation: 'reload' })` activé
