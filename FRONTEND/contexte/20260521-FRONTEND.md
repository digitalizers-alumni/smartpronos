## Suggestions utilisateur — à intégrer

### Comportement des scores initiaux
- Un match "À pronostiquer" doit afficher **0 - 0** par défaut dans le formulaire (pas de valeur vide pour ne pas influencer l'utilisateur) — déjà OK avec les defaults du formulaire.

### Nouveau statut / comportement match (à formaliser)
Proposition de raffiner les statuts pour le parcours utilisateur :

| État du match | Statut badge | Bouton action |
|---|---|---|
| `scheduled` + **aucun prono** | "À pronostiquer" | "Créer mon prono" → prérempli 0-0 |
| `scheduled` + **prono existant** | "À pronostiquer" | "Modifier mon prono" → prérempli avec le score existant |
| `locked` | "Pronos clos" | Désactivé |
| `finished` + **prono fait** | "Match joué" | Afficher : résultat réel vs mon prono + points gagnés |
| `finished` + **aucun prono** | "Match joué" | Afficher : résultat réel + "Tu n'as pas joué ce match" |

### Vue match terminé (complément US-FE-033)
Quand un match est fini, la carte de détail doit afficher côte à côte :
- Le **résultat officiel** (home - away)
- Le **prono de l'utilisateur** (home - away)
- Les **points gagnés** sur ce match
- Microcopy : "🎯 Score exact !" / "👍 Bon résultat" / "Pas pour cette fois"
